# Регистрация пациента в клинике

## Участники

- Пациент
- Регистратор
- Информационная система клиники

## Описание процесса

Пациент обращается в клинику и передает регистратору необходимые данные для регистрации. Регистратор вводит полученную информацию в информационную систему и проверяет ее корректность. Если данные заполнены неправильно или не полностью, пациенту сообщается о необходимости их исправить, после чего проверка выполняется повторно. Если данные корректны, регистратор проверяет наличие свободного времени для записи к врачу. Если подходящего времени нет, пациенту предлагается выбрать другое время. Если свободное время найдено, система создает запись пациента на прием. После этого данные о записи сохраняются в системе, а пациенту отправляется подтверждение регистрации. Сохранение данных и отправка подтверждения выполняются параллельно. После успешного выполнения этих действий процесс регистрации завершается.
