# Flowchart — Алгоритм проверки условий для записи пациента

Это алгоритм проверки условий, необходимых для того, чтобы создать запись пациента на приём: проверка корректности введённых данных и проверка наличия свободного времени.

```mermaid
flowchart TD
    A([Начало: данные пациента введены в систему]) --> B{Данные корректны?}
    B -- Нет --> C[Сообщить пациенту о необходимости исправить данные]
    C --> D[Ввести исправленные данные]
    D --> B
    B -- Да --> E{Есть свободное время?}
    E -- Нет --> F[Предложить пациенту другое время]
    F --> E
    E -- Да --> G([Конец: можно создать запись на приём])
```
