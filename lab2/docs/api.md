# API документация (lab2, Node-RED)

Эндпоинты реализованы в Node-RED (ноды `http in` и `http response`), файл потока: [`../flows/flow-08-endpoints.json`](../flows/flow-08-endpoints.json).

Базовый адрес: `http://localhost:1880`

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/text` | простой текст |
| GET | `/api/info` | JSON с двумя полями |
| GET | `/api/items` | список предметов, query-параметр `limit` |
| GET | `/api/items/:id` | один предмет по номеру, path-параметр `id` |

---

## GET /api/text

Возвращает простой текст.

**Параметры:** нет.

**Запрос:**
```bash
curl http://localhost:1880/api/text
```

**Ответ (200):**
```
Привет от Node-RED! Автор: Gavrilik, группа ИИ.
```

---

## GET /api/info

Возвращает JSON с двумя полями.

**Параметры:** нет.

**Запрос:**
```bash
curl http://localhost:1880/api/info
```

**Ответ (200, application/json):**
```json
{
  "student": "Gavrilik",
  "group": "ИИ"
}
```

---

## GET /api/items

Возвращает список предметов. Без параметров возвращает все три предмета.

**Query-параметры:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `limit` | целое число > 0 | нет | сколько первых элементов вернуть |

**Запрос без параметров:**
```bash
curl http://localhost:1880/api/items
```

**Ответ (200):**
```json
[
  { "id": 1, "name": "Ноутбук" },
  { "id": 2, "name": "Мышь" },
  { "id": 3, "name": "Клавиатура" }
]
```

**Запрос с `limit`:**
```bash
curl "http://localhost:1880/api/items?limit=2"
```

**Ответ (200):**
```json
[
  { "id": 1, "name": "Ноутбук" },
  { "id": 2, "name": "Мышь" }
]
```

**Запрос с ошибкой (некорректный `limit`):**
```bash
curl -i "http://localhost:1880/api/items?limit=abc"
```

**Ответ (400):**
```json
{ "error": "limit must be a positive integer" }
```

---

## GET /api/items/:id

Возвращает один предмет по номеру.

**Path-параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `id` | целое число > 0 | номер предмета |

**Успешный запрос:**
```bash
curl http://localhost:1880/api/items/2
```

**Ответ (200):**
```json
{ "id": 2, "name": "Мышь" }
```

**Ошибка: id не число или не положительное:**
```bash
curl -i http://localhost:1880/api/items/abc
```

**Ответ (400):**
```json
{ "error": "id must be a positive integer" }
```

**Ошибка: предмета с таким id нет:**
```bash
curl -i http://localhost:1880/api/items/99
```

**Ответ (404):**
```json
{ "error": "item not found", "id": 99 }
```

---

## Коды ответов

| Код | Значение |
|-----|----------|
| 200 | успешный запрос |
| 400 | некорректный параметр (`id` или `limit`) |
| 404 | предмет с указанным `id` не найден |

## Как проверить

Эндпоинты открываются в браузере по адресам из таблицы выше (при запущенном контейнере `mynodered`). Для просмотра кода ответа в терминале используй `curl -i`, в браузере вкладку Network (F12).
